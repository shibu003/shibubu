# Security policy

## Supported versions

Shibubu is alpha. Only the latest commit on the default branch gets security fixes.

## Reporting a vulnerability

Please **do not** report security issues in public issues, pull requests or discussions.

Report them privately through GitHub Security Advisories:

1. Go to the repository's **Security** tab.
2. Click **Report a vulnerability**.
3. Describe the issue, the affected version or commit, steps to reproduce, and the impact you expect.

If you see no option to report privately, open a public issue that only asks for a private contact, with no details of the vulnerability.

We will acknowledge the report, investigate, and coordinate a fix and its disclosure with you. Please give us reasonable time to fix the issue before you disclose it publicly.

## Scope

Areas of particular interest:

- Actions that run without the approval they should require (sending, writing, deleting)
- Leaks of tokens or credentials (`GITHUB_TOKEN`, OAuth tokens in the Keychain, model provider API keys) into logs, files or network requests
- Code generated by a model or imported from a repository running outside its sandbox
- Desktop control (the Accessibility bridge) acting on a different window or app than the one you approved
