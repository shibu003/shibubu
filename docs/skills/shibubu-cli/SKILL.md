# Shibubu CLI

Run `shibubu skills get shibubu-cli` to read the version-matched guide, then follow it.
`shibubu` knows which project this terminal belongs to (SHIBUBU_PROJECT_ID).
If `shibubu` is not found, ask the person to open a terminal in a Shibubu project and press Install on the notice at the top right (Install CLI & skill).
